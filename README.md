# Ольховская средняя школа

Адаптивная главная страница школьного сайта на обычных HTML и CSS. Сборка и локальный сервер не требуются.

## Запуск

Откройте `index.html` в любом современном браузере.

## Где менять содержимое

- Тексты, контакты, новости и ссылки находятся в `index.html`.
- Цвета, размеры и адаптивные правила находятся в `styles.css`. Основные цвета собраны в переменных в начале файла.
- Изображения находятся в папке `images`.

## Баннер

Большой баннер главной страницы хранится в `images/school.png`. Рекомендуемая пропорция изображения — 3:1.

## Шрифт

Oswald загружается из Google Fonts. Если интернет недоступен, браузер использует запасные системные шрифты `Arial Narrow` и `Arial`.
